# 📊 KNN Classification Project

This project uses the K-Nearest Neighbors (KNN) algorithm to perform classification on a dataset using Python and scikit-learn.

## 📁 Overview
The dataset (`KNN_Project_Data.csv`) includes multiple numeric features and a target label (**`TARGET CLASS`**) that the model aims to predict.

## 🔍 Process
- Import and inspect the dataset
- Normalize features using `StandardScaler`
- Split the data into training and testing sets
- Train the KNN model
- Evaluate results with confusion matrix and classification report
- Experiment with different values of K to improve accuracy

## 📈 Outcome
By adjusting the value of K, the model’s performance can be optimized, leading to better prediction accuracy and lower error rates.

## 🧰 Tools & Libraries
- pandas  
- numpy  
- matplotlib  
- scikit-learn
