# 🌲 Machine Learning Project: Trees & Forests

## 👋 About This Project

This project explores two popular machine learning algorithms:

* Decision Trees
* Random Forests

The main idea is to see how they work and compare their performance on a dataset.

## 💡 What I Did

* Cleaned and prepared the dataset
* Built a Decision Tree model
* Built a Random Forest model
* Compared their accuracy
* Visualized the results

## ⚙️ Tools & Libraries

* Python
* Jupyter Notebook
* Pandas & NumPy
* Scikit-learn
* Matplotlib / Seaborn

## 📉 Key Insight

Decision Trees are simple and easy to understand, but Random Forests usually perform better because they combine multiple trees.
